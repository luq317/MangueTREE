# MangueTREE manual

MangueTREE is an app that calculates the structure and phytosociology of mangrove forests from the field spreadsheet (one row per stem). This manual follows the order in which you use the app: how to build the spreadsheet, how to upload the data in each analysis, what each analysis does, how to save and how to use the results.

## Where to start

1. [What MangueTREE is for](01-what-it-is-for.md): what it calculates and what it does not do.
2. [Open the app](02-open-the-app.md): Windows and macOS version, or from the source code.
3. [Build the spreadsheet](03-build-the-spreadsheet.md): columns, codes, species, plot area and the template to download.
4. [Sidebar and settings](04-sidebar-and-settings.md): language, region, species table, DBH classes, style and units.
5. [Single plot](05-single-plot.md): one plot, one year.
6. [Multiple plots](06-multiple-plots.md): compare plots and calculate the IVI.
7. [Temporal analysis](07-temporal.md): the same plot over several years.
8. [Colonization](08-colonization.md): regeneration of juveniles (preview).
9. [Export and use the results](09-export-and-use.md): tables, figures, PDF report and how to use the numbers.
10. [Troubleshooting](10-troubleshooting.md): warnings and how to solve them.
